Privacy Policy

Last updated: 2026-09-29

Domek Home Automation is a private, single-user application. It is used only by its owner, on the owner's own Google account and the owner's own hardware.

What it accesses

With the owner's consent, it uses the Google Smart Device Management API to read the state of, and send commands to, the owner's own Google Nest thermostat (for example temperature, mode and set point).

How the data is used and stored

The data is used only to show and control the thermostat in the owner's own home-automation system. It stays on the owner's own network and devices. The OAuth credentials the app needs are stored on the owner's own systems. Nothing is stored on this website.

Sharing

The data is not sold, shared with, or disclosed to anyone else, and it is not used for advertising. The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and revocation

The owner can revoke the app's access at any time from their Google Account's third-party access settings, and can delete the app's stored credentials from their own systems.

Changes

If this policy changes, the updated version will be published on this page.
