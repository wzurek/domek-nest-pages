Domek Home Automation

Domek Home Automation is a private, single-user home-automation setup that runs on the owner's own hardware. It connects the owner's own Google Nest thermostat to a local HomeKit bridge so the thermostat can be viewed and controlled from the owner's own devices.

It uses the Google Smart Device Management API and is used only by its owner. It is not offered to the public, and it does not collect data from anyone else.
